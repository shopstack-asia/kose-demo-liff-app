# KOSE LIFF Application

LINE LIFF Application for KOSE built with Next.js App Router.

## Tech Stack

- Next.js 14 (App Router)
- React 18
- Ant Design v5
- TypeScript

## Development

```bash
npm install
npm run dev
```

## Architecture

- Client (LIFF App) → Next.js API Routes → Commerce Suite API (Mock)
